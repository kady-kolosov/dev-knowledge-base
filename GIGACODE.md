# Правила GigaCode

## SDD (Specification-Driven Development)

В этом проекте используется строгий подход Specification-Driven Development (SDD):

1. **Spec-first**: Любая работа начинается с написания спецификации (spec).
2. **Требуется одобрение**: Агент НЕ должен писать код или вносить изменения без явного одобрения спецификации пользователем.
3. **Реализация только по запросу**: После одобрения спецификации агент реализует только то, что было описано, и только когда ему скажут.

## Основное правило

Не вносить правки, не создавать новые файлы и не изменять существующий код без явного запроса от пользователя.
